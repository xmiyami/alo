# Лабораторная №4 по предоставленному отчёту

Это отдельный комплект. Не смешивайте его со старой папкой Lab4.

## Установка и запуск Windows 11

1. Скачайте Lab4-report.zip и распакуйте через «Извлечь всё».
2. Скопируйте ВСЁ содержимое Lab4-report в C:\STUDENT\ИИ-551\Lab4 (старые файлы предварительно сохраните отдельно). Если группа другая, замените название.
3. script1.vbs и script2.vbs самостоятельные: common.vbs и PowerShell им НЕ нужны. Для script3.js рядом требуются calculator.ps1 и text1.txt.
4. Закройте все окна Калькулятора и Блокнота, переключите раскладку на английскую. Сохраните нужный буфер обмена.
5. Запустите script1.vbs двойным щелчком и подтвердите начало. Не трогайте клавиатуру и мышь до результата в Блокноте. Ожидается «Результат: 54».
6. Сохраните результат Блокнота вручную (Ctrl+S), например task1-result.txt. Закройте Калькулятор и Блокнот.
7. Запустите script2.vbs. Ожидаются «Шестнадцатеричный результат: 176» и «Десятичный результат: 374». Калькулятор вернётся в обычный режим. Сохраните результат вручную.
8. Для третьего задания запустите run.cmd и выберите 3. Или в адресной строке Проводника введите cmd, нажмите Enter, затем выполните cscript //nologo //E:JScript script3.js.
9. Диалог выбора: HEX — Да; DEC — Нет, Да; OCT — Нет, Нет, Да; BIN — Нет, Нет, Нет. Отмена прекращает запуск.
10. Дождитесь окончания (несколько минут для всего файла), откройте text2.txt. Он перезаписывается при повторении. В нём есть заголовок основания и строки «выражение = результат».

## Отличия от отчёта

Первые два задания повторяют подход отчёта: Run, AppActivate по русскому/английскому заголовку, SendKeys, Ctrl+C/Ctrl+V. Добавлены очистка Калькулятора, ожидание активации и проверка её успеха. Работают с классическим и современным интерфейсом при поддержке указанных сочетаний клавиш. Результат первого задания вставляется из Калькулятора, а не записывается константой.

В третьем задании исправлены недоступный десятичный выбор, несовместимость String.trim со старым JScript и проверка недопустимых цифр. Арифметические операции выполняются через Калькулятор, как требует исходный PDF. Для этого используется calculator.ps1. Преобразование оснований и порядок операций выполняет JScript. Примеров шесть — из вашего отчёта. Числовые результаты выводятся без префиксов, как в образце отчёта.

Отчёт противоречит своему коду в формате text2.txt: в примерах перечислены только числа, а код записывает выражение = результат. Здесь сохранён более понятный формат с выражениями; эталонные файлы содержат только числа для удобства сравнения.

## Ограничения

Windows GUI в облаке недоступен: эти сценарии здесь НЕ проходили сквозной проверки на Windows. Логика парсера прошла 48 тестов в Linux; отдельные эталоны для шести примеров также проверены. Перед сдачей необходим реальный запуск и собственные скриншоты. Заявления приложенного чужого отчёта о результатах не считаются проверкой вашего запуска.

SendKeys зависит от активного окна. Не открывайте несколько Блокнотов/Калькуляторов, не переключайте фокус, не запускайте сценарии параллельно. Если кириллическая подпись вводится неверно, сообщите фактический результат и текущую раскладку. Не отключайте защиту Windows при блокировке сценариев.

VBScript должен быть установлен как компонент Windows. Для третьего задания требуется Windows PowerShell 5.1; дочерний процесс запускается с ExecutionPolicy Bypass, без постоянного изменения политики. Корпоративные запреты этим не обходятся.

Точность — IEEE-754 double, целые до 9007199254740991, до 12 цифр дробной части в выводе, ненулевой остаток помечается [truncated]. Разделитель во входе — точка; префиксы 0x, 0, @. Запись 08 ошибочна; 0.5 десятична. text1.txt сохраняйте как ASCII/ANSI или UTF-8 без BOM. Выход text2.txt — UTF-16LE.

Чужие ФИО и группа из предоставленного отчёта намеренно не скопированы. Для сдачи используйте свои данные и настоящие результаты запуска.
