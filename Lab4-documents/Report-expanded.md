## 3. Основные понятия
Windows Script Host (WSH) — среда выполнения сценариев Windows. wscript.exe показывает сообщения WScript.Echo в окнах, cscript.exe выводит их в консоль. Файл .vbs выполняется движком VBScript, .js в этой работе — движком JScript WSH, а не браузером и не Node.js.
WScript — объект среды выполнения: через него доступны Sleep, Echo, Quit, ScriptFullName. WScript.Shell — отдельный COM-объект, создаваемый CreateObject; он предоставляет Run, Exec, AppActivate, SendKeys и Popup. Scripting.FileSystemObject — ещё один COM-объект для работы с файлами и каталогами.
Процесс — выполняющийся экземпляр программы. Окно — элемент её интерфейса. PID идентифицирует процесс, HWND — окно; это разные сущности. AppActivate принимает PID или заголовок окна. Он не является общим методом перечисления всех процессов. Приложение может создать несколько окон, а при запуске современного приложения процесс-лаунчер может передать управление другому процессу.
Буфер обмена — общий ресурс сеанса Windows. Ctrl+C просит активное приложение скопировать данные, Ctrl+V вставляет их в активное приложение. Наличие на дисплее правильного числа не гарантирует, что оно было скопировано или вставлено.

## 5. Задание 1: вычисление 9 × 6
### 5.1. Последовательность действий
Сценарий создаёт WScript.Shell, предупреждает пользователя, запускает calc.exe и notepad.exe с двухсекундными паузами. Затем выбирает обычный режим Калькулятора, очищает предыдущее состояние и отправляет 9*6=. После Ctrl+C активируется Блокнот, вводится подпись и выполняется вставка Ctrl+V. В конце отправляется Enter.
```vb
CalcKeys "%1"
CalcKeys "{ESC}"
CalcKeys "9*6="
CalcKeys "^c"
NoteKeys "Результат: "
NoteKeys "^v"
NoteKeys "{ENTER}"
```
CalcKeys и NoteKeys — пользовательские процедуры, а не встроенные команды Windows. Они сначала вызывают процедуру активации нужного окна, затем SendKeys и задержку 700 мс. Такой порядок уменьшает вероятность отправки клавиш до готовности интерфейса, но фиксированная задержка не гарантирует успех при любой нагрузке.

## 6. Задание 2: сложение F7 и 7F
### 6.1. Последовательность действий
После запуска приложений выбираются режим «Программист» (Alt+3) и основание HEX (F5). После очистки вводится F7{+}7F=. HEX-ответ копируется в Блокнот. Затем активируется Калькулятор, выбирается DEC (F6), копируется десятичное представление того же результата. Завершающая команда Alt+1 возвращает обычный режим.
```vb
CalcKeys "%3"
CalcKeys "{F5}"
CalcKeys "{ESC}"
CalcKeys "F7{+}7F="
CalcKeys "^c"
NoteKeys "Шестнадцатеричный результат: "
NoteKeys "^v"
NoteKeys "{ENTER}"
CalcKeys "{F6}"
CalcKeys "^c"
NoteKeys "Десятичный результат: "
NoteKeys "^v"
NoteKeys "{ENTER}"
CalcKeys "%1"
```
| Запись SendKeys | Значение |
| %3 | Alt+3 — выбор режима «Программист» в используемой реализации Калькулятора. |
| {F5} | Нажатие F5: выбор HEX в режиме программиста. |
| F7 | Два обычных символа: цифра F и цифра 7, то есть число F7₁₆. |
| {F7} | Функциональная клавиша F7. Это другая команда; в программистском режиме выбирает OCT. |
| {+} | Буквальный знак сложения. Без скобок + обозначает модификатор Shift. |
| {F6} | Нажатие F6: выбор DEC. |
| %1 | Alt+1 — возврат обычного режима. |
### 6.2. Проверка числа
F7₁₆ = 15 × 16 + 7 = 247₁₀. 7F₁₆ = 7 × 16 + 15 = 127₁₀. Сумма равна 374₁₀. Деление на 16 даёт остатки 6, 7, 1; при чтении в обратном порядке получается 176₁₆.
Ожидаемый формат вывода: «Шестнадцатеричный результат: 176», затем «Десятичный результат: 374». Основание меняет запись числа, а не само значение.
[IMAGE 4|Рисунок 2 — На снимке второго задания видны 176 и 374; Калькулятор отображён в обычном режиме. Русские подписи искажены.]
Снимок подтверждает два ожидаемых числовых значения и обычный вид окна в момент снимка. Однако поясняющие слова не отображены в требуемом виде. Исправление записи подписи в Unicode-файл описано в разделе 5.3; факт повторного успешного оформления по этому снимку не устанавливается.

### 7.5. Разбор записи чисел
Префиксы: 0x или 0X — основание 16, @ — основание 2, ведущий 0 перед другой цифрой — основание 8, без префикса — основание 10. Запись 0.5 считается десятичной, потому что после первого нуля стоит точка; 010.4 считается восьмеричной. Цифры проверяются: например, 08 и @102 недопустимы.
Число переводится во внутреннее десятичное значение по позиционной формуле. Для целой части используется n = n × base + digit; для дробной — сумма digit/base^k. Пример 0x1.A = 1 + 10/16 = 1.625; 0x2.8 = 2 + 8/16 = 2.5; сумма 4.125. Дробный разделитель входа всегда точка, независимо от региональных настроек.
parseInt(c, 16) в number() используется для получения значения одной цифры 0…F; затем её значение сравнивается с выбранным основанием. Это предотвращает частичное принятие недопустимого числа. Переменная prefix в данном листинге не участвует в возвращаемом значении; фактически для результата number() нужны base и value.
### 7.6. Парсер и приоритет операций
parse хранит позицию pos и пропускает пробелы через ws. atom обрабатывает число, унарный знак и выражение в скобках. term объединяет атомы операциями * и /. expr объединяет термы операциями + и −. Вложенный вызов expr при встрече скобок обеспечивает отдельный разбор подвыражения.
Для 2+3*4 строится узел + с левым ребёнком 2 и правым ребёнком — узлом *(3,4). Поэтому сначала вычисляется 12, затем 14. Для (2+3)*4 корнем становится *, сначала получается 5, затем 20. Циклы в term и expr обеспечивают левую ассоциативность: 8/4/2 = (8/4)/2 = 1, а не 4.
Дерево хранит объекты kind: number, unary или binary. evaluate рекурсивно получает значения детей. Для binary он вызывает переданный callback calculator(a, op, b), а callback — bridge. Для unary знак применяется в JScript; это не отдельное нажатие операции в Калькуляторе. Если бинарных вызовов не было, identity передаёт итоговое число в приложение для чтения.
Входные выражения не исполняются как программный код. В этой версии JScript парсер включён непосредственно в script3.js, поэтому eval для загрузки отдельного файла тоже не требуется. Строка module.exports относится к возможности тестирования ядра в Node.js; в WSH API помещается в root.LabEngine.
### 7.7. Форматирование и ограничения точности
format делит число на целую и дробную части. Целая часть преобразуется whole.toString(base), буквы A…F переводятся в верхний регистр. Дробная часть многократно умножается на основание; её целая часть даёт очередную цифру. После 12 цифр процесс останавливается, при ненулевом остатке добавляется [truncated]. Это усечение, а не округление до ближайшего.
Функция format сначала добавляет префикс результата, но строка записи через replace удаляет его, чтобы получить формат как в образце: например, 176 вместо 0x176. Заголовок Output base: 16 сообщает, в каком основании читать эти числа. Префиксы внутри исходного выражения слева сохраняются. Таким образом, основания входа и выхода — разные настройки.
Внутренние Number в JScript — IEEE-754 double. Для безопасных целых проверяется модуль не больше 9007199254740991; дроби могут иметь погрешности двоичного представления. Длина входного выражения ограничена 2000 символами, глубина atom — 64, число его вызовов — 500. Нельзя описывать эту реализацию как вычисления с произвольной точностью.
### 7.8. Ошибки и коды завершения
Ошибки строки перехватываются try/catch: записывается Line N: выражение -> ERROR: сообщение, затем программа продолжает следующие строки. Поэтому наличие text2.txt ещё не означает успех. Проверяются содержимое строк и число errors в финальном сообщении. При наличии хотя бы одной ошибки выполняется Quit(1), иначе Quit(0).
Примеры причин: недопустимая цифра; незакрытая скобка; лишний символ; деление на ноль; отсутствие calculator.ps1; отказ активации окна; отсутствие результата в буфере обмена. Если получено Calculator did not copy a result to the clipboard, это ошибка обмена с приложением, а не доказательство неверной записи выражения.

## Приложение Г. Листинг script3.js из исходного Word-документа
Листинг сохранён без изменения алгоритма; визуальный перенос длинных строк в документе не является изменением исходного кода.
```js
// Windows Script Host JScript (run with cscript.exe //nologo script3.js).
var fso = new ActiveXObject("Scripting.FileSystemObject");
var shell = new ActiveXObject("WScript.Shell");
var dir = fso.GetParentFolderName(WScript.ScriptFullName);
/* ES3: Windows Script Host JScript + Node.js test runner. No eval(). */
(function (root) {
    function fail(s) { throw new Error(s); }
    function parse(source) {
        var pos = 0, count = 0;
        if (source.length > 2000) fail("Expression exceeds 2000 characters");
        function ws() { while (/\s/.test(source.charAt(pos)) && pos < source.length) pos++; }
        function number() {
            ws(); var start = pos, base = 10, prefix = "";
            if (source.substr(pos, 2).toLowerCase() === "0x") { base = 16; pos += 2; prefix = "0x"; }
            else if (source.charAt(pos) === "@") { base = 2; pos++; prefix = "@"; }
            else if (source.charAt(pos) === "0" && /[0-9]/.test(source.charAt(pos + 1)) && pos + 1 < source.length) base = 8;
            var digits = "", dots = 0;
            while (pos < source.length && /[0-9a-fA-F.]/.test(source.charAt(pos))) {
                var c = source.charAt(pos++); if (c === ".") dots++;
                else if (parseInt(c, 16) >= base) fail("Invalid digit for base " + base + " at " + pos);
                digits += c;
            }
            if (!digits || digits === "." || dots > 1) fail("Invalid number at " + (start + 1));
            var parts = digits.split("."), n = 0, i, scale = base;
            for (i = 0; i < parts[0].length; i++) n = n * base + parseInt(parts[0].charAt(i), 16);
            if (parts.length > 1) for (i = 0; i < parts[1].length; i++) { n += parseInt(parts[1].charAt(i), 16) / scale; scale *= base; }
            if (!isFinite(n) || Math.abs(n) > 9007199254740991) fail("Number exceeds safe numeric range");
            return {kind: "number", value: n};
        }
        function atom(depth) {
            if (depth > 64 || ++count > 500) fail("Expression too complex");
            ws(); var c = source.charAt(pos), a;
            if (c === "+" || c === "-") { pos++; return {kind: "unary", op: c, child: atom(depth + 1)}; }
            if (c === "(") { pos++; a = expr(depth + 1); ws(); if (source.charAt(pos++) !== ")") fail("Missing closing parenthesis"); return a; }
            return number();
        }
        function term(depth) { var a = atom(depth), c; ws(); while ((c = source.charAt(pos)) === "*" || c === "/") { pos++; a = {kind:"binary", op:c, left:a, right:atom(depth)}; ws(); } return a; }
        function expr(depth) { var a = term(depth), c; ws(); while ((c = source.charAt(pos)) === "+" || c === "-") { pos++; a = {kind:"binary", op:c, left:a, right:term(depth)}; ws(); } return a; }
        var tree = expr(0); ws(); if (pos !== source.length) fail("Unexpected character at " + (pos + 1)); return tree;
    }
    function evaluate(tree, calculator) {
        if (tree.kind === "number") return tree.value;
        if (tree.kind === "unary") return (tree.op === "-" ? -1 : 1) * evaluate(tree.child, calculator);
        var a = evaluate(tree.left, calculator), b = evaluate(tree.right, calculator);
        if (tree.op === "/" && b === 0) fail("Division by zero");
        var n = calculator(a, tree.op, b);
        if (!isFinite(n) || Math.abs(n) > 9007199254740991) fail("Result exceeds safe numeric range");
        return n;
    }
    function format(n, base) {
        if (base !== 2 && base !== 8 && base !== 10 && base !== 16) fail("Unsupported base");
        if (!isFinite(n) || Math.abs(n) > 9007199254740991) fail("Result exceeds safe numeric range");
        var sign = n < 0 ? "-" : "", x = Math.abs(n), whole = Math.floor(x), fraction = x - whole;
        var text = whole.toString(base).toUpperCase(), tail = "", i, d;
        for (i = 0; i < 12 && fraction > 0; i++) { fraction *= base; d = Math.floor(fraction); tail += d.toString(base).toUpperCase(); fraction -= d; }
        tail = tail.replace(/0+$/, "");
        return sign + (base === 16 ? "0x" : base === 8 ? "0" : base === 2 ? "@" : "") + text + (tail ? "." + tail : "") + (fraction > 0 ? " [truncated]" : "");
    }
    var api = {parse:parse, evaluate:evaluate, format:format};
    if (typeof module !== "undefined" && module.exports) module.exports = api; else root.LabEngine = api;
}(this));

function quote(s) { return '"' + s + '"'; }
function bridge(mode, a, op, b) {
    var req = fso.BuildPath(fso.GetSpecialFolder(2), fso.GetTempName());
    var res = fso.BuildPath(fso.GetSpecialFolder(2), fso.GetTempName());
    var file = fso.CreateTextFile(req, true, true);
    file.WriteLine(mode); file.WriteLine(String(a)); file.WriteLine(op); file.WriteLine(String(b)); file.Close();
    var code = shell.Run('powershell.exe -NoLogo -NoProfile -STA -ExecutionPolicy Bypass -File ' + quote(dir + '\\calculator.ps1') + ' -Request ' + quote(req) + ' -Response ' + quote(res), 0, true);
    fso.DeleteFile(req);
    if (!fso.FileExists(res)) throw new Error('PowerShell bridge failed to start');
    file = fso.OpenTextFile(res, 1, false, -1); var text = file.ReadAll(); file.Close(); fso.DeleteFile(res);
    var lines = text.split('\r\n');
    if (code !== 0 || lines[0] !== 'OK') throw new Error(text);
    var value = Number(lines[1]); if (!isFinite(value)) throw new Error('Invalid Calculator response');
    return value;
}
var choice = shell.Popup('Output base: Yes = hexadecimal, No = another base, Cancel = exit.', 0, 'Lab4 - output base', 3 + 32);
if (choice === 2) WScript.Quit(0);
var base = 16;
if (choice === 7) {
    choice = shell.Popup('Yes = decimal; No = octal/binary; Cancel = exit.', 0, 'Lab4 - output base', 3 + 32);
    if (choice === 2) WScript.Quit(0);
    if (choice === 6) base = 10;
    else {
        choice = shell.Popup('Yes = octal; No = binary; Cancel = exit.', 0, 'Lab4 - output base', 3 + 32);
        if (choice === 2) WScript.Quit(0);
        base = choice === 6 ? 8 : 2;
    }
}
var input = dir + '\\text1.txt', output = dir + '\\text2.txt';
if (!fso.FileExists(input)) { WScript.Echo('Missing text1.txt'); WScript.Quit(1); }
// Input is ASCII (expressions only), output UTF-16LE for Russian Windows compatibility.
var reader = fso.OpenTextFile(input, 1, false, 0), results = [], lineNumber = 0, failures = 0;
while (!reader.AtEndOfStream) {
    var line = reader.ReadLine(); lineNumber++;
    if (/^\s*$/.test(line)) continue;
    try {
        var tree = LabEngine.parse(line), calls = 0;
        var result = LabEngine.evaluate(tree, function(a, op, b) { calls++; return bridge('binary', a, op, b); });
        if (!calls) result = bridge('identity', result, '', 0);
        results.push(line + ' = ' + LabEngine.format(result, base).replace(/^(-?)(0x|@)/, '$1').replace(/^(-?)0(?=[0-7])/, '$1'));
    } catch (e) { failures++; results.push('Line ' + lineNumber + ': ' + line + ' -> ERROR: ' + e.message); }
}
reader.Close();
var writer = fso.CreateTextFile(output, true, true);
writer.WriteLine('Output base: ' + base);
for (var i = 0; i < results.length; i++) writer.WriteLine(results[i]);
writer.Close();
WScript.Echo('Written: ' + output + '; expressions: ' + results.length + '; errors: ' + failures);
WScript.Quit(failures ? 1 : 0);
```
