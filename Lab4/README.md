# Лабораторная работа №4

Дисциплина: «Операционные системы, среды и оболочки».
Тема: взаимодействие со стандартными приложениями Windows на VBScript/JScript.

Начните с docs/Windows11.md или docs/Windows11.pdf. Полный отчёт: docs/Report.docx и docs/Report.pdf.

## Состав

- script1.vbs — 9 × 6 через Калькулятор; результат 54 в Блокноте.
- script2.vbs — F7 + 7F в режиме «Программист»; 176 и 374 в Блокноте; возврат в «Обычный».
- script3.js — чтение text1.txt, диалог выбора основания, вычисление и запись text2.txt.
- common.vbs — общие функции VBScript.
- engine.js — разбор выражений и преобразование чисел, совместимый с JScript ES3.
- calculator.ps1 — мост к окнам Windows: WScript.Shell, AppActivate, SendKeys и чтение буфера обмена.
- run.cmd — меню запуска.
- tests/test-engine.js — автоматические проверки ядра, требуют Node.js только для разработки.
- results/expected-results.json — эталон для всех четырёх оснований; это не результаты запуска Windows.
- results/cloud-validation.txt — журнал реально выполненных облачных проверок.

Никаких npm-пакетов и установки Python для запуска на Windows не требуется. ZIP нужно полностью распаковать.

## Границы проверки

Облачная машина работает под Linux. Проверены ядро, эталоны и синтаксис JavaScript. Windows Script Host, PowerShell и окна Калькулятора/Блокнота здесь отсутствуют: сквозной запуск трёх сценариев не проверен. Скриншоты Windows не подделывались.

Сценарии управляют видимыми окнами и заменяют буфер обмена. Запускайте по одному, не используйте мышь/клавиатуру до завершения. Удалённый доступ к ноутбуку не используется.
