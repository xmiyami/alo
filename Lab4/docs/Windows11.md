# Установка и запуск на Windows 11

## 1. Что потребуется

Нужны обычный сеанс рабочего стола Windows 11, приложения «Калькулятор» Microsoft и «Блокнот», Windows PowerShell 5.1 и Windows Script Host. Интернет нужен только при отсутствии системного компонента. Node.js, Visual Studio и Python для запуска лабораторной не нужны.

VBScript объявлен Microsoft устаревающим компонентом. В разных сборках Windows 11 он может быть отключён. JScript здесь означает старый движок Windows Script Host, а не браузер и не Node.js.

## 2. Распаковка и требуемая папка

1. Скачайте Lab4-complete.zip, нажмите правой кнопкой и выберите «Извлечь всё». Не запускайте файлы внутри ZIP.
2. Откройте Проводник (Win+E), диск C:, создайте папку STUDENT, внутри — папку вашей группы, например ИВТ-21. При запросе Windows разрешите создание папки. Администратор нужен только если права на C: ограничены.
3. Скопируйте целиком папку Lab4 из архива в папку группы. Пример итогового пути: C:\STUDENT\ИВТ-21\Lab4. Слово «группа» из PDF заменяется вашим обозначением группы.
4. В Проводнике включите «Вид → Показать → Расширения имён файлов». Проверьте, что script1.vbs не превратился в script1.vbs.txt.
5. Просмотрите исходники. Если Windows блокирует скачанные файлы, в свойствах ZIP выберите «Разблокировать» и распакуйте заново. Не отключайте антивирус и Smart App Control. На управляемом компьютере обращайтесь к администратору при блокировке политикой.

## 3. Проверка компонентов

Откройте «Пуск», введите «Калькулятор», запустите и закройте его. Повторите с «Блокнотом». Если их нет, установите приложения Microsoft Calculator и Windows Notepad из Microsoft Store.

Нажмите Win+R, введите cmd, нажмите Enter. Выполните:

    where cscript
    powershell.exe -NoProfile -Command "$PSVersionTable.PSVersion"

Если VBScript отсутствует: «Параметры → Система → Дополнительные компоненты» (в некоторых сборках: «Приложения → Дополнительные компоненты») → просмотр/добавление компонентов → VBScript → установить. Если его нет в списке, проверьте доступность компонента для своей сборки и ограничения организации; JScript не заменяет VBScript в первых двух заданиях.

## 4. Подготовка перед каждым запуском

Закройте остальные экземпляры Калькулятора. Сохраните важное содержимое буфера обмена: оно будет заменено результатами. Переключите раскладку на английскую (Win+Space). Не запускайте программы от имени администратора. Экран должен оставаться разблокированным, без других диалогов поверх окон.

Откройте Lab4 и дважды нажмите run.cmd. Выберите цифру 1, 2 или 3. До сообщения Exit code не переключайте окна, не печатайте и не нажимайте мышью. Калькулятор будет многократно активироваться. Один переход занимает около секунды, выражения с несколькими операциями могут обрабатываться десятки секунд.

Мост запускается с параметром -ExecutionPolicy Bypass только для дочернего процесса PowerShell. Постоянные настройки системы не меняются. Параметр не отменяет AppLocker, WDAC и групповые политики; при таких запретах нужна помощь администратора. Не меняйте глобальную политику и не отключайте защиту.

## 5. Первое задание

Выберите 1. Ожидается вычисление 9 * 6 = 54 в Калькуляторе, затем открытие Блокнота с текстом «9 * 6 = 54». Сохранённый результат: results\script1-result.txt. Код завершения должен быть 0.

## 6. Второе задание

Выберите 2. Калькулятор переключается в «Программист» (Alt+3), в HEX (F5), вычисляет F7 + 7F. Затем переключается в DEC (F6), копирует результат и возвращается в «Обычный» (Alt+1).

В Блокноте должны появиться две строки:

    Шестнадцатеричный результат: 176
    Десятичный результат: 374

Результат: results\script2-result.txt. Проверьте обычный вид Калькулятора. При несоответствии значений сценарий завершится ошибкой вместо выдачи заранее заданного ответа.

## 7. Третье задание

Откройте text1.txt в Блокноте. Каждая непустая строка — одно выражение; знак равенства в конце не нужен. Используйте только латинские цифры/буквы A–F, пробелы, точку, скобки и операции + - * /. Сохраняйте text1.txt как ANSI или UTF-8 без BOM: данные состоят из ASCII-символов. UTF-16 и UTF-8 с BOM для входа не поддерживаются.

Примеры: 0xA.8+@1.1; (0x10+010)*@10; 010.4/2; -5+2. Префиксы: 0x — HEX, @ — BIN, ведущий 0 перед другими цифрами — OCT, без префикса — DEC. Поэтому 010 — восемь, а 08 — ошибка. Десятичная дробь 0.5 допустима.

Выберите 3. Диалоги по-английски обходят проблемы кодировки JScript; кнопки Windows могут называться «Да», «Нет», «Отмена»:

- HEX: Да в первом диалоге.
- DEC: Нет в первом, Да во втором.
- OCT: Нет в первом, Нет во втором, Да в третьем.
- BIN: Нет в первом, Нет во втором, Нет в третьем.
- Отмена в любом диалоге прекращает запуск, не создавая новый результат.

После окончания откройте text2.txt. Первая строка задаёт основание, остальные содержат исходный пример и результат в порядке входа. Пустые строки пропускаются. Неверная строка помечается ERROR с номером, обработка остальных продолжается; общий код завершения 1 при любой ошибке. При успешной обработке код 0.

Файл text2.txt и файлы results\script*-result.txt перезаписываются при повторном запуске. Перед повторением сохраните нужные результаты под другими именами. text2.txt записывается как UTF-16LE и нормально открывается Блокнотом.

## 8. Проверка результатов и скриншоты

При DEC для готового text1.txt ожидаются последовательно: 54; 374; 48; 12; 4.25; 14; 20; -3; 3.5; 255; 5.25; 0.75. Для других оснований сверяйтесь с results\expected-results.json. Повторите запуск для всех четырёх оснований, каждый раз сохраняйте text2.txt под отдельным именем.

Для проверки ошибок временно сохраните копию text1.txt, добавьте строки 1/0, 08, (2+3 и 2+3*4. Три строки должны получить ERROR, последняя — 14 в DEC. Верните исходный входной файл.

Для отчёта сделайте реальные скриншоты Win+Shift+S: первое вычисление и Блокнот, две строки второго задания и обычный режим Калькулятора, диалог выбора основания, входной и выходной файлы третьего задания. Облачный отчёт содержит места для этих снимков, но не вымышленные доказательства запуска Windows.

## 9. Если возникла ошибка

«Нет обработчика сценариев VBScript»: установите дополнительный компонент VBScript. «Windows Script Host отключён»: это политика компьютера, обратитесь к администратору. Открытие .js в редакторе вместо запуска: используйте run.cmd или команду ниже.

Cannot activate Calculator / startup timed out: проверьте установку Калькулятора, закройте его окна и повторите. При другой реализации окна или политике запрета активации может потребоваться отдельная адаптация моста; данный путь не проверен на реальном Windows в облаке.

Unrecognized Calculator output: проверьте язык/регион Windows и десятичный разделитель. Мост учитывает текущую региональную культуру, но нестандартный язык интерфейса может потребовать адаптации. Не считайте отсутствующий результат успешным вычислением.

Unexpected hexadecimal calculation: убедитесь в английской раскладке и поддержке сочетаний F5/F6 в Калькуляторе Microsoft. Не взаимодействуйте с окнами во время расчёта. При сообщении Magnitude below supported keyboard precision используйте числа с модулем не меньше 1e-31.

Для ручного запуска из cmd (замените группу своей):

    cd /d "C:\STUDENT\ИВТ-21\Lab4"
    cscript.exe //nologo script1.vbs
    cscript.exe //nologo script2.vbs
    cscript.exe //nologo //E:JScript script3.js

Запускайте по одной команде и дожидайтесь завершения. Если окно не реагирует, Ctrl+C в консоли остановит сценарий; при выполняющемся скрытом мосте дождитесь его завершения либо завершите только относящийся к этому запуску PowerShell через Диспетчер задач.

## 10. Дополнительные тесты для разработчика

При установленном Node.js LTS выполните из Lab4: node tests\test-engine.js. Ожидаются 48 успешных проверок. Это проверка парсера и преобразований с тестовой арифметикой, а не автоматизация окон Windows. Node.js не умеет выполнять script1.vbs, script2.vbs и Windows-часть script3.js.
