# Обновление совместимости

Мост теперь ищет процессы CalculatorApp, Calculator, calc и win32calc. Это исправляет пропуск классического Калькулятора при поиске окна. Замените calculator.ps1 рядом с common.vbs и script1.vbs. Если окно открывается, сообщение об ошибке активации не означает, что нужна переустановка приложения. Проверка Windows GUI в облаке по-прежнему недоступна.
